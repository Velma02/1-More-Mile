1 More Mile website

index.html            Page structure and text (landing page + register form)
css/style.css         All styling: colours, fonts, layout
js/config.js          YOUR Google Web app URL (SCRIPT_URL) - paste it here once
js/main.js            Page switching, scrolling, form sending
checkin.html          Staff check-in scanner (only payment-confirmed registrations can be checked in)
images/               Logos and photos (hero.jpg, photo-sunrise.jpg, photo-shoe.jpg, logos)
apps-script/Code.gs   Paste into Google Apps Script (NOT run in VS Code)

Open the folder in VS Code and run index.html with Live Server.
Paste your Apps Script Web app URL into SCRIPT_URL in js/config.js (used by both pages).
Upload index.html, checkin.html, css/, js/ and images/ together when hosting.
